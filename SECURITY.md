# Security Policy

## Supported versions

Security fixes are provided for the latest released version of Resy.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/martythedev-tech/Resy/security/advisories/new) instead of opening a public issue.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Please do not include credentials, access tokens, private deployment details, or personal data in a report.
